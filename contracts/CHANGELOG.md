# Contracts changelog

The REST API spec is generated by springdoc from controller annotations (`/v3/api-docs`, disabled in prod). This directory holds the internal interface contracts that builders work from, plus notes on wire-visible behaviour changes.

## 2026-11-01 — trajectory-service-refactor

| Contract | Version | Change | Breaking |
|---|---|---|---|
| `trajectory-service.md` | 1.0.0 | New. `TrajectoryService` API, cache key `{#bullet, #req}`, `UnknownBulletException`. Executor renamed to `trajectoryExecutor` | Internal: yes (controllers and engine signature). Wire: no |
| `rate-limit-config.md` | 1.0.0 | New. `app.ratelimit.*` properties, per-client + global buckets, `@RateLimited` interceptor, proxy IP extraction | See below |
| `physics-tables-bean.md` | 1.0.0 | New. `PhysicsTables` bean. `BallisticsEngine(PhysicsTables, MeterRegistry)` | Internal: yes. Wire: no |

Wire-visible behaviour changes (all non-breaking unless marked):
- 429 responses now have an `application/problem+json` body, and `Retry-After` is computed (≥ 1 s) instead of fixed at `60`.
- `POST /api/trajectories/custom` is now rate-limited (`SINGLE` tier) and can return 429.
- Requests that fail validation now consume a rate-limit token.
- A null or absent `bulletId` on `POST /api/trajectory` and on batch items returns 400 instead of 500.
- Pending approval, **breaking** (tightened validation): `CustomBulletRequest.name` `maxLength` 64.
